title: "Limits and defaults"
---

- **Configurable:** a variable from [Configuration](/reference/configuration), or "No" for a constant in the code.
- **Per runner:** the count resets when the session's runner restarts (idle exit, `!restart`).
- **Memory and CPU:** to change them, see [Resource limits](/self-hosting/operate).
