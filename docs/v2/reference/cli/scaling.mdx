<Warning>
**Not available in v2.** Memory is fixed at launch in v2, so scaling calls return `501`.
</Warning>

Set the size when you create the sandbox — see [Sandbox sizes](/v2/sandboxes/sizes).

This page exists so the v2 docs mirror v1 page-for-page. See
[Migrating from v1](/v2/migrating-from-v1) for the full list of removed and changed behaviour,
and [the v1 page](/reference/cli/scaling) for how this worked before.
