---
title: "Preview URLs"
description: "Exposing a port from inside the sandbox"
---

Preview URLs are unchanged from the current runtime.

```typescript
const preview = await sandbox.createPreviewURL({ port: 3000 });
console.log(preview.hostname); // sb-<id>-p3000.<your-domain>

const all = await sandbox.listPreviewURLs();
await sandbox.deletePreviewURL(3000);
```

Anything listening on that port inside the sandbox is reachable at the returned hostname.

## Auth

```typescript
const preview = await sandbox.createPreviewURL({
  port: 3000,
  authConfig: { /* ... */ },
});
```

A preview URL can require a bearer token, and the token can be rotated with
`rotatePreviewAuthToken()`. Without auth configured, the URL is open to anyone who has it.

## Lifetime

A preview URL lives as long as its sandbox — which on this runtime is at most 8 hours. Links
you hand to someone else will stop working when the sandbox ends, so treat them as short-lived
rather than as stable addresses.
