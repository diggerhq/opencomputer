---

This quickstart creates your first OpenComputer project, runs its hello-world
agent locally, and opens a React app that can steer it.

## Prerequisites

- Node.js 22 or newer
- An OpenComputer account

## 1. Install and log in

```bash
npm install --global @opencomputer/cli
opencomputer login
opencomputer whoami
```

## 2. Create a project

```bash
opencomputer init my-agent
cd my-agent
npm install
```

Use `opencomputer init .` to initialize the current directory instead. The CLI
creates or links the matching project in your OpenComputer organization and
adds one `hello-world` agent.

## 3. Run the agent server

In the first terminal:

```bash
npm run dev
```

This watches the files under `opencomputer/` and starts the local agent API.
It does not start the web application.

## 4. Run the React app

In a second terminal:

```bash
npm run dev:web
```

Open the Vite URL and send the suggested hello-world prompt. The generated
`useAgent` hook streams the response and reuses the session for follow-up
messages.

## 5. Customize the agent

Edit `opencomputer/agents/hello-world/instructions.md`. Add tools, connections,
skills, channel declarations, or workspace files beside it. React UI code stays
under `src/`.

```text
my-agent/
├── opencomputer/
│   ├── project.ts
│   └── agents/hello-world/
└── src/
```

## 6. Deploy

```bash
opencomputer deploy --alias production
```

Each source change produces an immutable deployment version. Open the project
in the dashboard and select **Agent playground** to test the deployed agent.
