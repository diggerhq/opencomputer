OpenComputer turns any machine into a multiplayer coding agent.

## Why move coding agents off your laptop

A lot of us outgrow our local machines, for a few reasons:

- **RAM.** Our agents run parallel builds, and preview environments run locally too.
- **Context overload.** We become meat proxies, copy-pasting between our agents and Slack.
- **The rest of the team.** We want nontechnical teammates to ship features and fixes alongside us.

All of these are easy to solve by moving to multiplayer coding in the cloud.

## Where you use it

OpenComputer targets first-class support for Slack. You can also work with it from the web dashboard, the API and the CLI.

## Start small, scale later

Get started on a single machine or in the cloud. When you need more, scale out to multiple machines; sessions stay portable between them.
