## Before you start

- A Slack workspace. If you are not an admin, Slack lets you request approval for the app.
- A GitHub account that can install a GitHub App on the repositories the agent will work in.
- A Claude Pro or Max, or ChatGPT Plus or Pro subscription, unless you pay for model usage with OpenComputer credits.

## Set up

Sign in at [app.opencomputer.dev/computer](https://app.opencomputer.dev/computer). The page walks through four steps.

<Steps>
  <Step title="Choose your coding agent">
    Pick Claude Code or Codex and connect the subscription it runs on, or pick OpenComputer credits.
  </Step>
  <Step title="Add OpenComputer to Slack">
    Click **Add to Slack** and approve the app. The service creates your organization's computer; the page shows its status until it is `Online`.
  </Step>
  <Step title="Connect GitHub">
    Install the GitHub App and pick the repositories. The three most recently pushed are cloned on the computer; the others are cloned when a session first checks them out. The agent can push branches and open pull requests in all of them.
  </Step>
  <Step title="Give it a first task">
    Mention `@computer` in a channel, or send it a direct message. The page shows the mention to copy.

    ```text
    @computer why is the checkout test flaky?
    ```

    You do not have to wait for `Online`: a message sent while the computer starts is picked up once it is on.
  </Step>
</Steps>

The reply streams into the thread under your message. That thread is now a session: reply in it to continue, without a mention.

## Teammates

Anyone in the Slack workspace can mention `@computer`. A session belongs to the person who started its thread.
